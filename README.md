# FoodSaver: Human-Computer Interaction Project

FoodSaver is a mobile application concept for reducing household food waste. The application helps users track food stock, monitor expiration dates through a visual calendar, receive timely reminders, and get recipe suggestions based on ingredients already available at home. It also includes a community component for sharing recipes and a donation feature for connecting surplus food with local charities.

This repository contains the design and research documentation produced for the CIS422 Human-Computer Interaction course project at Imam Abdulrahman Bin Faisal University.

For a general summary of the project, see [`Project_Overview.pdf`](Project_Overview.pdf).

## Core Features

| Feature | Description |
| --- | --- |
| Inventory tracking | Add food items and view them in a calendar-style layout showing expiration dates. |
| Expiration reminders | Automatic notifications sent before food items expire. |
| Recipe suggestions | Recipes recommended based on ingredients the user already has, selected through checkboxes rather than manual text entry. |
| Community and donation | A space for sharing and rating recipes, plus a donation feature that connects surplus food with local charities. |

The design process followed a User-Centered Design (UCD) framework, combined with Fogg's Behavior Model (FBM) as a persuasive design layer.

## Research Summary

The design decisions in this project were informed by ten semi-structured interviews and an online survey completed by thirty-five participants, all adults involved in household food management. Findings from this research directly shaped the four core features of the application, including the priority placed on expiration reminders and checkbox-based ingredient selection over manual text entry.

## Prototyping Process

| Phase | Focus | Outcome |
| --- | --- | --- |
| Phase 1 | Pre-design analysis | Review of competing systems and identification of key user tasks. |
| Phase 2 | User research | Interviews, survey, and task analysis that informed the initial paper prototype. |
| Phase 3 | Design refinement | Revised interfaces addressing usability issues, leading to a high-fidelity prototype built in Figma. |
| Phase 4 | Usability testing | Think-Aloud sessions with three participants, evaluated against Nielsen's usability heuristics. |
